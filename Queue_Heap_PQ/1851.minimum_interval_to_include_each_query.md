# 1851.Minimum Interval to Include Each Query

难度: Hard
标签: Array、Heap、Sorting

![1851](https://github.com/donnapersonal/picx-images-hosting/raw/master/image.8z78q33exx.webp)

限制：
- 1 <= intervals.length <= 10^5
- 1 <= queries.length <= 10^5
- intervals[i].length == 2
- 1 <= lefti <= righti <= 10^7
- 1 <= queries[j] <= 10^7

## 解题

思路： `排序 + 离线查询 + 优先队列（小根堆）`

注意到，题目中查询的顺序并不会影响答案，并且涉及到的区间也不会发生变化，因此，可以考虑将所有的查询按照从小到大的顺序进行排序，同时将所有的区间按照左端点从小到大的顺序进行排序。

使用一个`优先队列（小根堆） pq` 来维护当前所有的区间，队列的每个元素是一个二元组 `(v,r)`，表示一个区间长度为 `v`，右端点为 `r` 的区间。初始时，优先队列为空。另外，定义一个指针 `i`，指向当前遍历到的区间，初始时 `i=0`

按照从小到大的顺序依次遍历每个查询 `(x,j)`，并进行如下操作：
- 如果指针 `i` 尚未遍历完所有的区间，且当前遍历到的区间 `[a,b]` 的左端点小于等于 `x`，那么将该区间加入优先队列中，并将指针 `i` 后移一位，循环此过程
- 如果优先队列不为空，且堆顶元素的区间右端点小于 `x`，那么将堆顶元素弹出，循环此过程
- 此时，如果优先队列不为空，则堆顶元素就是包含 `x` 的最小区间，将其长度 `v` 加入答案数组 `res` 中

在上述过程结束后，返回答案数组 `res` 即可

```python
class Solution:
    def minInterval(self, intervals: List[List[int]], queries: List[int]) -> List[int]:
        n, m = len(intervals), len(queries)
        # Sort intervals by their left endpoints.
        intervals.sort(key=lambda interval: interval[0])
        # Store each query together with its original index,
        # then process queries in increasing order.
        sorted_queries = sorted(
            (query, index) for index, query in enumerate(queries)
        )

        # Default res is -1 when no valid interval exists.
        res = [-1] * m

        # Each heap entry is: (interval size, right endpoint)
        pq = []
        # Pointer to the next interval that has not been added.
        i = 0

        for query, original_index in sorted_queries:
            # Add every interval whose left endpoint is <= query.
            while i < n and intervals[i][0] <= query:
                left, right = intervals[i]
                heapq.heappush(pq, (right - left + 1, right))
                i += 1
            
            # Remove intervals that end before the query.
            while pq and pq[0][1] < query:
                heapq.heappop(pq)
            
            # The smallest valid interval is at the top.
            if pq:
                res[original_index] = pq[0][0]
        
        return res
```
```java
class Solution {
    public int[] minInterval(int[][] intervals, int[] queries) {
        int n = intervals.length;
        int m = queries.length;
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
        int[][] sortedQueries = new int[m][2];
        for (int i = 0; i < m; i++) {
            sortedQueries[i][0] = queries[i];
            sortedQueries[i][1] = i;
        }
        Arrays.sort(sortedQueries, (a, b) -> Integer.compare(a[0], b[0]));
        int[] res = new int[m];
        Arrays.fill(res, -1);
        PriorityQueue<int[]> pq = new PriorityQueue<>(
            (a, b) -> {
                if (a[0] != b[0]) {
                    return Integer.compare(a[0], b[0]);
                }
                return Integer.compare(a[1], b[1]);
            }
        );
        int index = 0;
        for (int[] queryPair : sortedQueries) {
            int query = queryPair[0];
            int original_idx = queryPair[1];
            while (index < n && intervals[index][0] <= query) {
                int left = intervals[index][0];
                int right = intervals[index][1];
                int size = right - left + 1;
                pq.offer(new int[]{size, right});
                index++;
            }

            while (!pq.isEmpty() && pq.peek()[1] < query) {
                pq.poll();
            }

            if (!pq.isEmpty()) {
                res[original_idx] = pq.peek()[0];
            }
        }
        return res;
    }
}
```

- 时间复杂度 `O(n×logn+m×logm)`，其中 `n` 和 `m` 分别是数组 `intervals` 和 `queries` 的长度
- 空间复杂度 `O(n+m)`
