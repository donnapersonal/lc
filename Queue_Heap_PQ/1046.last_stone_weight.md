# 1046.Last Stone Weight

难度: Easy
标签: Array、Heap、PQ

![1046](https://github.com/donnapersonal/picx-images-hosting/raw/master/image.5q84mgofbw.webp)

限制：
- 1 <= stones.length <= 30
- 1 <= stones[i] <= 1000

## 解题

```python
class Solution:
    def lastStoneWeight(self, stones: List[int]) -> int:
        pq = []
        for stone in stones:
            heapq.heappush(pq, -stone)
        
        while len(pq) > 1:
            x, y = heapq.heappop(pq),heapq.heappop(pq)
            if x != y:
                heapq.heappush(pq, x-y)
        
        return 0 if len(pq) == 0 else -pq[0]
```
```java
class Solution {
    public int lastStoneWeight(int[] stones) {
        PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder()); 
        for (int stone : stones) {
            pq.offer(stone);
        }

        while (pq.size() > 1) {
            int x = pq.poll();
            int y = pq.poll();
            if (x != y) {
                pq.offer(x-y);
            }
        }
        return pq.isEmpty() ? 0 : pq.peek();
    }
}
```

- 时间复杂度：`O(nlogn)`，其中 `n` 是石头数量。每次从队列中取出元素需要花费 `O(logn)` 的时间，最多共需要粉碎 `n−1` 次石头
- 空间复杂度：`O(n)`
