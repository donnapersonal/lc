难度: Easy
标签: Binary Tree、DFS

限制:
- The number of nodes in the tree is in the range [0, 5000].
- -10^4 <= Node.val <= 10^4

## 解题

**核心思路**
- 使用一个辅助函数：`getHeight(node)`，该函数通常返回以 `node` 为根的子树的高度

然而，当发现子树不平衡时，它会返回：`-1`，值 `-1` 是一个哨兵值，表示：该子树不平衡

对于每个节点：
- 递归计算左子树的高度
- 如果左子树返回 -1，则立即返回 -1
- 递归计算右子树的高度
- 如果右子树返回 -1，则立即返回 -1
- 检查高度差
- 如果差值大于 1，则返回 -1
- 否则，返回当前子树的高度

最终结果为：`getHeight(root) != -1`

**为什么要使用后序遍历？**

要判断当前节点是否平衡，必须先知道：
- 左子树的高度
- 右子树的高度

因此，在处理当前节点之前，先处理两个子节点 -> `左 → 右 → 节点`

这正是`后序遍历`

**为什么哨兵值有效?**

通常，子树的高度是非负的：0, 1, 2, 3, ...

因此，`-1` 可以安全地表示无效或不平衡的子树

假设左子树已经不平衡：`leftHeight = -1`

无需继续检查父节点，因为包含不平衡子树的树本身也是不平衡的

立即将：`-1` 向上传递

这实现了`提前终止`

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        def get_height(node: Optional["TreeNode"]) -> int:
            if not node:
                return 0
            
            left_height = get_height(node.left)
            right_height = get_height(node.right)
            if left_height == -1 or right_height == -1:
                return -1
            
            if abs(left_height - right_height) > 1:
                return -1
            
            return 1 + max(left_height, right_height)
            
        return get_height(root) != -1
```
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isBalanced(TreeNode root) {
        return getHeight(root) != -1;
    }

    private int getHeight(TreeNode root) {
        if (root == null) return 0;
        int leftHeight = getHeight(root.left);
        int rightHeight = getHeight(root.right);
        if (leftHeight == -1 || rightHeight == -1) {
            return -1;
        }
        if (Math.abs(leftHeight - rightHeight) > 1) {
            return -1;
        }
        return Math.max(leftHeight, rightHeight) + 1;
    }
}
```

设：n = 节点数量，h = 树的高度

- 时间复杂度: `O(n)`，每个节点最多被访问一次
  - 在每个节点上，执行的操作耗时为常数级：两次比较，一次绝对值差计算，一次求最大值操作，因此：`O(n)`

- 空间复杂度: `O(h)`，递归栈中，树的每一层最多包含一次调用。
  - 平衡树: `h = O(log n)`，因此：空间复杂度 = `O(log n)`
  - 倾斜树: `h = O(n)`，因此：空间复杂度 = `O(n)`
