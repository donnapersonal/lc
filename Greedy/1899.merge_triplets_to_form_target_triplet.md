# 1899.Merge Triplets to Form Target Triplet

难度: Medium
标签: Array、Greedy

![1899](https://github.com/donnapersonal/picx-images-hosting/raw/master/image.232l7n1eo1.webp)

限制：
- 1 <= triplets.length <= 10^5
- triplets[i].length == target.length == 3
- 1 <= ai, bi, ci, x, y, z <= 1000

## 解题

思路：合并尽可能多的三元组

**提示 1**

设数组 triplets 的长度为 n

题目等价于让我们选择若干个下标 i1, i2,⋯,ik，且 i1 < i2 < ⋯ < ik ≤ n，使得：

![text](https://github.com/donnapersonal/picx-images-hosting/raw/master/image.3uvk2nhuca.webp)

这里的正确性在于，我们每次执行的操作是选择两个三元组每一个位置中的较大值，因此：
- 同一个下标对应的三元组选择多次是没有意义的，每个三元组会被选择 0 或 1 次
- 选择三元组的顺序也是可以任意交换的

**提示 2**

对于任意一个三元组 (ai, bi, ci)：
- 如果 ai > x 或者 bi > y 或者 ci > z，那么选择该三元组是不合理的
- 否则，一定有 ai ≤ x 并且 bi ≤ y 并且 ci ≤ z。由于所有的操作都是 max 操作，因此选择这个三元组并没有什么坏处，它不会让我们原本得到 (ai, bi, ci) 的某种可行选择变得不可行，因为：(max{x, ai}, max{y, bi}, max{z, ci})=(x, y, z) 是显然成立的

思路与算法

根据提示 2，只需要遍历所有的三元组，如果 ai ≤ x 并且 bi ≤ y 并且 ci ≤ z，那么我们就选择该三元组

设 a,b,c 分别是我们选择的所有三元组 ai, bi, ci 中的最大值。在遍历结束后，如果有：(a,b,c)=(x,y,z) 则返回 true，否则返回 false

```python
class Solution:
    def mergeTriplets(self, triplets: List[List[int]], target: List[int]) -> bool:
        x, y , z = target
        a, b, c = 0, 0, 0
        for ai, bi, ci in triplets:
            # Ignore any triplet that would exceed the target.
            if ai <= x and bi <= y and ci <= z:
                a = max(ai, a)
                b = max(bi, b)
                c = max(ci, c)
        
        return (a, b, c) == (x, y, z)
```
```java
class Solution {
    public boolean mergeTriplets(int[][] triplets, int[] target) {
        int x = target[0], y = target[1], z = target[2];
        int a = 0, b = 0, c = 0;
        for (int[] triplet : triplets) {
            int ai = triplet[0], bi = triplet[1], ci = triplet[2];
            if (ai <= x && bi <= y && ci <= z) {
                a = Math.max(a, ai);
                b = Math.max(b, bi);
                c = Math.max(c, ci);
            }
        }
        return a == x && b == y && c == z;
    }
}
```

- 时间复杂度：`O(n)`，其中 n 是数组 triples 的长度
- 空间复杂度：`O(1)`
