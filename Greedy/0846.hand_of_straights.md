# 846.Hand of Straights

难度: Medium
标签: Array、Greedy

![846](https://github.com/donnapersonal/picx-images-hosting/raw/master/image.232l7n1eo1.webp)

限制：
- 1 <= hand.length <= 10^4
- 0 <= hand[i] <= 10^9
- 1 <= groupSize <= hand.length

## 解题

每个顺子一定有最小和最大的一张牌，每次一幅牌里也一定有最小的一张，这张牌必须有顺子是满足所有牌都在顺子里的充要条件。把它的顺子去掉以后，又会有一张新的最小的牌，如此反复，直到没有牌

```python
class Solution:
    def isNStraightHand(self, hand: List[int], groupSize: int) -> bool:
        # Every group must contain exactly groupSize cards.
        if len(hand) % groupSize != 0:
            return False
        
        counts = Counter(hand)
        # Process distinct card values from smallest to largest.
        for start in sorted(counts.keys()):
            groups = counts[start]
            # This value may have already been consumed by earlier groups.
            if groups == 0:
                continue

            # All copies of start must begin separate groups.
            for card in range(start, start + groupSize):
                if counts[card] < groups:
                    return False

                counts[card] -= groups

        return True
```
```java
class Solution {
    public boolean isNStraightHand(int[] hand, int groupSize) {
        if (hand.length % groupSize != 0) {
            return false;
        }

        Map<Integer, Integer> counts = new HashMap<>();
        for (int card : hand) {
            counts.put(card, counts.getOrDefault(card, 0) + 1);
        }

        List<Integer> starts = new ArrayList<>(counts.keySet());
        Collections.sort(starts);
        for (int start : starts) {
            int groups = counts.get(start);
            if (groups == 0) {
                continue;
            }

            for (int card = start; card < start + groupSize; card++) {
                int available = counts.getOrDefault(card, 0);
                if (available < groups) {
                    return false;
                }
                counts.put(card, available - groups);
            }
        }
        return true;
    }
}
```

- 时间复杂度：`O(n + k log k)`
  - 构建频率映射表：`O(n)`
  - 对不同的键值进行排序：`O(k log k)`
  - 内层循环的每一次成功操作都会消耗至少一张此前未使用的牌，因此批量处理的总工作量上限为 `O(n)`
  - 由于：`k <= n`，总体上界为：`O(n log n)`
- 空间复杂度：频率映射表和已排序的键值占用 `O(k)`
