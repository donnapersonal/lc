# 703.Kth Largest Element in a Stream

难度: Easy
标签: Design、Heap

![703](https://github.com/donnapersonal/picx-images-hosting/raw/master/image.7axvgixwrt.png)

限制：
- 0 <= nums.length <= 10^4
- 1 <= k <= nums.length + 1
- -10^4 <= nums[i] <= 10^4
- -10^4 <= val <= 10^4
- At most 10^4 calls will be made to add.

## 解题

```python
class KthLargest:

    def __init__(self, k: int, nums: List[int]):
        self.k = k
        self.pq = []
        # 将 nums 装入小顶堆，保留下前 k 大的元素
        for num in nums:
            heapq.heappush(self.pq, num)
            if len(self.pq) > k:
                heapq.heappop(self.pq)

    def add(self, val: int) -> int:
        # 维护小顶堆只保留前 k 大的元素
        heapq.heappush(self.pq, val)
        if len(self.pq) > self.k:
            heapq.heappop(self.pq)

        # 堆顶就是第 k 大元素（即倒数第 k 小的元素）
        return self.pq[0]
```

```java
class KthLargest {
    private final int k;
    private final PriorityQueue<Integer> pq;

    public KthLargest(int k, int[] nums) {
        this.k = k;
        this.pq = new PriorityQueue<>();
        for (int num : nums) {
            pq.offer(num);
            if (pq.size() > k) {
                pq.poll();
            }
        }
    }
    
    public int add(int val) {
        pq.offer(val);
        if (pq.size() > k) {
            pq.poll();
        }
        return pq.peek();
    }
}
```
